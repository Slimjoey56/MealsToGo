# Meals To Go

A small food-ordering project repository with a beginner-friendly Python command-line restaurant application.

## Python CLI restaurant app

The `python_cli/` folder contains a mini restaurant ordering experience built with Python's standard library. Customers can browse a menu, add meals to a basket, remove items and check out.

**Run the app:**

```bash
python python_cli/main.py
```

**Run its tests:**

```bash
python -m unittest discover -s python_cli -p "test_*.py" -v
```

See [python_cli/README.md](python_cli/README.md) for setup, features and the Python concepts demonstrated.

## Existing Expo application

The repository also retains the original Expo / React Native starter application at the repository root. The Python CLI is kept in its own folder so it does not overwrite the existing mobile app.

## Development transparency

The Python CLI was created with AI assistance as a guided learning project. Review, run and modify the code to build independent understanding before describing it as independently authored.
